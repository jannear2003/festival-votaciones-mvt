# Propuesta visual del grupo

## Estado

Propuesta recibida como maqueta frontend independiente.

## Elementos recibidos

- HTML estático.
- Hoja de estilos.
- JavaScript para el laboratorio musical.
- Imagen de fondo pendiente de validar su procedencia y licencia.

## Objetivo de integración

Adaptar al proyecto Django:

- Paleta cromática.
- Hero principal.
- Tarjetas translúcidas.
- Botones y navegación.
- Elementos culturales.
- Laboratorio musical opcional.

## Restricciones

- No reemplazar la lógica dinámica de Django.
- No modificar modelos ni migraciones.
- No alterar registro, login, logout o autorización.
- No activar partículas en formularios.
- No modificar Django Admin.
- No publicar recursos sin licencia conocida.
- Mantener aprobadas las pruebas académicas.

## Primera fase

La primera adaptación incluirá únicamente:

- Variables de color.
- Fondo y superficies Liquid Glass moderadas.
- Hero del portal público.
- Tarjetas dinámicas de votaciones.
- Navegación compatible con sesiones y roles.

La estela del cursor y las explosiones musicales se evaluarán después.
