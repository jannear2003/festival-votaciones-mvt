Diseño del módulo de participantes
1. Objetivo
Representar a las personas individuales y agrupaciones que pueden inscribirse en una categoría de una edición del Festival.

2. Alcance inicial
El módulo permitirá:

Crear participantes.
Diferenciar participante individual y agrupación.
Asociar una cuenta responsable.
Registrar nombre artístico.
Registrar procedencia.
Incorporar una reseña artística.
Incorporar una fotografía o imagen.
Activar o inactivar el registro.
Consultar el perfil desde la administración.
Utilizar participantes en futuras inscripciones.
3. Fuera del alcance inicial
Por el momento no se implementará:

Carga de documentos de identidad.
Información de menores de edad.
Inscripción oficial.
Evaluación de jurados.
Clasificación por rondas.
Votación pública.
Certificación de participantes.
4. Tipos de participante
Persona individual
Participante que compite de manera individual, aunque pueda presentarse con acompañantes.

Agrupación
Conjunto de integrantes que participa bajo un nombre artístico común.

5. Reglas preliminares
Cada participante debe tener una cuenta responsable.
El nombre artístico será obligatorio.
El tipo de participante será obligatorio.
Un participante podrá mantenerse inactivo sin eliminarse.
La fotografía será opcional.
No se almacenarán documentos reales durante el prototipo.
Los registros de demostración utilizarán datos sintéticos.
La inscripción será una entidad separada del participante.
6. Relación futura
Usuario → Participante → Inscripción → Edición → Categoría → Ronda → Evaluación
